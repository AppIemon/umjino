# 화투 카드 이미지

이 폴더에 카드 이미지를 넣으면 섯다·고스톱이 **자동으로** 그 이미지를 씁니다.
코드는 건드릴 필요가 없습니다. 파일이 없으면 `public/js/hwatu.js`의 벡터 아트로 자동 대체됩니다.

## 파일 이름 규칙

`<월>-<번호>.png` — 48장. `.png` 외에 `.jpg` `.jpeg` `.webp` `.svg`도 자동 인식합니다
(`1-0` 파일의 확장자를 보고 나머지도 같은 확장자로 읽습니다).

세로형 비율(권장 90×140 안팎)이면 잘림 없이 들어갑니다.

## 주의

이미지를 넣기 전에 저작권을 확인하세요. 상용 화투 카드 도안은 보호 대상일 수 있습니다.
