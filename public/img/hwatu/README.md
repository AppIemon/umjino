# 화투 카드 이미지

섯다·고스톱이 쓰는 실제 카드 이미지 48장이 들어 있습니다.
출처와 라이선스는 `ATTRIBUTION.md`를 보세요 (CC BY-SA 4.0).

다른 카드 세트로 바꾸려면 **같은 파일명으로 덮어쓰기만** 하면 됩니다.
파일을 못 읽는 경우에만 `public/js/hwatu.js`의 벡터 아트로 대체됩니다.

## 파일 이름 규칙

`<월>-<번호>.png` — 48장. `.png` 외에 `.jpg` `.jpeg` `.webp` `.svg`도 자동 인식합니다
(`1-0` 파일의 확장자를 보고 나머지도 같은 확장자로 읽습니다).

세로형 비율(권장 90×140 안팎)이면 잘림 없이 들어갑니다.

## 이미지 규격

현재 파일은 240×384 PNG(세로/가로 1.6)입니다. 다른 비율을 쓰려면
`public/js/hwatu.js`의 `HW_CARD_RATIO`를 함께 바꾸세요.

## 주의

카드 세트를 교체할 때는 저작권을 확인하세요. 상용 화투 도안은 보호 대상일 수 있습니다.
